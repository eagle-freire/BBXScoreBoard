# BBXScoreBoard
Simple scoreboard for Beyblade X tourneys.

## Functionalities:
- [ ] Scoreboard for 2 players
- [ ] First to 4
- [ ] Buttons for spin finish, over finish, burst finish and extreme finish
- [ ] Penalty counter
- [ ] Timer for deck shuffling
- [ ] WebApp
